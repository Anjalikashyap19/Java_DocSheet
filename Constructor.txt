5. What is constructor overloading in Java ? write a example..

If a class having more than one constructor with the same name , then it is known as constructor overloading.

we can achieve constructor overloading by these way--
 by changing the data types of the formal  Argument .
 by changing order of the argument.
 By changing Number of the arguments.

 example---

 class Fruits
 {
    Fruits(int a, int b){
        system.out.println("first constructor");
    }
    Fruits(int a, int b, int c){
        system.out.println("second constructor called");
    }

    public staic void main(string[] args){
        Fruits f1 =new Fruits(10,8);
        Fruits f2 = new Fruits(11,9,6);
      
    }
 }

 output---
 first Constructor
 second Constructor called

 Advantage ---
 code reuseblity 
 we can initialize object in defferent different way.
