4.What is method overloading ? WAJP for method overloading.
it is a concept of compile time polymorphism .
when a class have more than one method with the same name , but different formal arguments, then it is known as 
method overloading.
we can achieve method overloading by following ways------
by changing  data types of the arguments.
by changing order of the formal arguments.
by changing no of formal arguments.

example program------

class A{
    public void sum(int a,int b){
        System.out.println("sum is"+(a+b));
    }

    public void sum(double a, double b){
        System.out.println("sum is"+(a+b));
    }

    public static void main(String[] args){
        A a1=new A();
       a.sum(7,9);
        a.sum(5.6,3.2);
    }
}

6.constructor overloading with example program?
constructor overloading is also a concept of compile time polymorphism,when a class more than  one constructor with 
the same name but different formal argiuments, we know it as constructor overloading.

we can achieve it is by 3 different ways----
*different number of formal arguments.
*By using different data type.
*By changing order of formal arguments.

Example-----

class A{
    A(){
        System.out.println("hello from start");
    }
    A(int a){
        System.out.println(a);
    }
    A(String a){
        System.out.println("Anjali Kr. Kashyap");
    }

    public static void main(String[] args){

       A a2=new A(19); // 19

7.Explain method Shadowing?WAJP also.
when super class and sub class having static method with the same name and same signature , but different implementation
then it is known as method shadowing.

in method shadowing alwas we get output based on referemce type.
it is only applicable for static methods.
for acheiving method shadowing we need is a relationship.
it is also known as method hiding.

example program--

class Animal{
    public static void eat(String a){
        System.out.println("animal is eating "+a);

    }


}
class Dog extends Animal{
    public static void eat(String a){
        System.out.println("dog is eating"+a);
    }
}

class AnimalDriver{
    public static void main(String args){

        Animal A = new Animal();
        A.eat("grass") ;// animal is eating grass

        Animal A1 =new Dog();
        Dog d=(Dog)A1;
       d.eat("grass"); //dog is eating grass.
    }
}

output--
Animal is eating grass.
dog is eating grass.

8. what is variable shadowing ? explain with example.

when a super class and sub class have variable with the same name but different value, then it is known as 
variable shadowing.

it is also known as variable hiding.
it is applicable for both static and non static variable.
to achieving variable shadowing we need is a relationship.
the result is based on reference type.

example--
class Animal
{
    int a=10;
    static int b=20;

}

class Dog extends Animal
{
    int a =12;
    static int b=19;
}

class AnimalDriver{
    public static void main(String[] args){

        Animal a1=new Animal();
        System.out.println(a1.a);

        Dog d1=new Dog();
        System.out.println( d1.a);//12
        System.out.println( d1.b); //19

        Animal a2=new Dog(); // upcasting
        Dog d2=(Dog)a2;    //downcasting

                 System.out.println(d2.a) ; //12
                 System.out.println(d2.b);  //19
    }
}

output--
10
12
19
