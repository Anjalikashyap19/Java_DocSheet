1.What is polymorphism and what are the types of it?

polymorphism is one of the oops cocept in which one object can able to perform different different behaviour 
at a same time.
it has two type ----
Compile time polymorphism
Run time polymorphism

compile time polymorphism also known as static polymorphism
and run time polymorphism is also known as dynamic polymorphism

2.Method binding?

it is a connection between method call statement and method definition .

3.What is compile time polymorphism and how to achieve it?
when the binding is achieved at the time of compilation then it is known as 
compile time polymorphism.
for  achieving compile time polymorphism we have 4 ways--
*By method overloading
*By constructor overloading
*By method shadowing
*By variable shadowing

4.What is method overloading ? WAJP for method overloading.
it is a concept of compile time polymorphism .
when a class have more than one method with the same name , but different formal arguments, then it is known as 
method overloading.
we can achieve method overloading by following ways------
by changing  data types of the arguments.
by changing order of the formal arguments.
by changing no of formal arguments.

example program------

class A{
    public void sum(int a,int b){
        System.out.println("sum is"+(a+b));
    }

    public void sum(double a, double b){
        System.out.println("sum is"+(a+b));
    }

    public static void main(String[] args){
        A a1=new A();
       a.sum(7,9);
        a.sum(5.6,3.2);
    }
}
